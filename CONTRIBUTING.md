# Contributing to Xernerx Suite

Thank you for your interest in contributing to the Xernerx suite! Please follow these guidelines to set up your local development environment and run the monorepo successfully.

## Prerequisites

- **Node.js** >= 20
- **pnpm** >= 11 (`corepack enable pnpm`)[cite: 3]
- **MongoDB** (running locally or via a remote URI)

## Getting Started

1. **Clone the repository:**

    ```bash
    git clone [https://github.com/xernerx/suite.git](https://github.com/xernerx/suite.git)
    cd suite
    ```
