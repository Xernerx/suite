# `@xernerx/styles` — Central Tailwind CSS v4 & Design Tokens

Houses the master stylesheet (`globals.css`) and CSS custom property design tokens for the **Modern Round Glassmorphism Pop** design language.

---

## 🎨 Core Design Tokens

- **Surface & Text Tokens:** `--background`, `--foreground`, `--text`, `--text-muted`, `--border` (automatically adapted across Light and Dark themes).
- **Accent & Semantic Tokens:** `--accent`, `--hover-accent`, `--accent-green`, `--accent-orange`, `--accent-red`.
- **Dynamic Scaling Tokens:** `--ui-gap`, `--ui-scale`, `--text-scale`.
- **Typography:** Display headings use `--font-fredoka`.
