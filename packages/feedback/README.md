# `@xernerx/feedback` — Route Feedback & Error Boundaries

Standardized loading states, error boundaries, and 404 views used by Next.js App Router `loading.tsx`, `error.tsx`, `global-error.tsx`, and `not-found.tsx` files across all `apps/*`.

---

## 🧩 Exported Components

- **`Loading`:** Animated glassmorphic loading spinner and skeleton state.
- **`Error`:** Recoverable route error boundary view with retry action and diagnostics.
- **`NotFound`:** Unified 404 page with quick navigation back to the active service or `xernerx.com`.
