## 🧭 Overview

The **Desktop** service is an Electron-powered application that wraps and renders the various Xernerx Suite services into a native desktop wrapper. It provides enhanced performance, deep system integration, and hardware-accelerated rendering.

---

## 🛠️ Core Features

- **Multi-Service Renderer:** Seamlessly hosts and renders web ecosystem services in a dedicated desktop environment.
- **GPU Acceleration:** Leverages hardware acceleration for smoother animations and high-performance rendering.
- **Native Enhancements:** Deep integration with desktop system notifications, tray controls, and local shortcuts.

---

## 🛠️ Tech Stack & Dependencies

- **Runtime:** Electron / Node.js
- **Framework:** React / Web Technologies
- **Styling:** Tailwind CSS
