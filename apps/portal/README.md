# `portal` — Xernerx Developer & Organization Portal (`portal.xernerx.com`)

The **Portal** application (`portal.xernerx.com`, dev port `4009`) is the dedicated creator, bot developer, and organization studio for the Xernerx Suite.

---

## 🌐 Environments

| Environment | URL                                                              | Description                                |
| :---------- | :--------------------------------------------------------------- | :----------------------------------------- |
| **Public**  | [`portal.xernerx.com`](https://portal.xernerx.com)               | Production developer & organization studio |
| **Canary**  | [`portal.canary.xernerx.com`](https://portal.canary.xernerx.com) | Pre-release staging portal                 |
| **Dev**     | [`portal.dev.xernerx.com`](https://portal.dev.xernerx.com)       | Local development tunnel (`:4009`)         |

---

## ✨ Key Capabilities

- **Personal & Organization Workspaces (`/`):** Switch seamlessly between your Personal Bot Workspace and multi-member Developer Organizations with custom RBAC roles, member invitations, linked servers, and shared Organization Credit Treasuries.
- **Bot Developer Studio (`/bots/[id]`):** Manage bot descriptions, category tags, vanity URLs, release notes, visual slash commands, 30-day growth telemetry charts, outbound webhooks (with local Electron IPC relay and delivery replay), and Spotlight boosts.
